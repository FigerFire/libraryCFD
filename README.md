# CFD Library

资料按主题整理，中英文版本放在同一主题目录中。

```text
library/
├── papers/
│   ├── ibm/                 # Immersed Boundary Method
│   ├── mpi/                 # MPI、并行与通信
│   ├── turbulence/          # 湍流
│   ├── combustion/          # 燃烧
│   ├── numerical-methods/   # 数值方法
│   ├── phase-change/        # 相变、凝结与沸腾
│   ├── level-set/           # Level Set / Ghost Fluid Method
│   └── application/         # 电解槽、气泡等应用论文及译稿
├── books/
│   ├── fundamentals/        # 基础教材
│   └── advanced/            # 进阶教材与专题文集
└──notes/                   # 项目笔记、分析文档与 TeX 源文件
```
